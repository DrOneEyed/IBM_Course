# IBM Course — Learning Materials

Structured course materials and exercises from an IBM professional development programme, organised week by week.

## Course Structure

```
Week 1/   — Foundations and core concepts
Week 2/   — Building on fundamentals
Week 3/   — Intermediate topics
Week 4/   — Advanced applications
Week 5/   — Final projects and assessments
```

## Purpose

This repository serves as a personal archive of coursework, exercises, and projects completed during the IBM course. Materials are organised chronologically by week for easy reference.

## Getting Started

Browse any week's folder to access the corresponding materials. Each week may contain:
- Lecture notes and reading materials
- Hands-on lab exercises
- Completed assignments and project files
